# Dan Dekker

I build first-party software, end to end: security, low-level and embedded systems, LLM tooling, backend, and frontend. I also dabble in creative coding and game design.

## Selected work

- **[baton](https://github.com/DanDekker/baton)** — Local auth broker for AI agents and MCP tools. Temporary credential leases keep secrets out of chats.
- **[webdev-gauntlet](https://github.com/DanDekker/webdev-gauntlet)** — Web development challenges and local evaluation for LLM agents.
- **[mesh.](https://github.com/DanDekker/mesh.)** — Interactive WebGL particle sculpture with six responsive forms. [See it live](https://dandekker.github.io/mesh./).
